## Husky 

Se configuró HUSKY para ejecutar validaciones antes de realizar commits.

### ¿Qué hace Husky en este proyecto?
Antes de permitir un commit, ejecuta una validación para asegurar que el proyecto compile correctamente y evitar subir cambios con errores.

### Beneficio
Esto ayuda a mantener el repositorio más limpio y reduce errores en el pipeline de GitHub Actions.
